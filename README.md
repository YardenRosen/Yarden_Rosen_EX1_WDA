# Yarden Rosen — Digital Business Card

A responsive personal website that introduces me as an SAP consultant and Computer Science student. The site presents my background, skills, SAP projects, and contact details in a single-page digital business card.

## Features

- About, skills, projects, and contact sections
- SAP project highlights in Cash & Treasury, HR, and Authorizations
- Responsive layout for mobile and desktop screens
- Light and dark themes using HTML and CSS
- Keyboard-accessible navigation and theme control
- GitHub and LinkedIn profile links

## Technologies

HTML and CSS only.

## View locally

Download or clone the repository, then open `index.html` in a web browser. No installation is required.

index.html          Page content and structure
